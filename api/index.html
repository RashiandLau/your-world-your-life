    手元で使う
    手元用の道具をダウンロード
    Node.js 18 以降を入れ、手元用の道具を新しいフォルダに展開してください。api/ と site/assets/ が一緒に入っています。フォルダへ移動してから、次の例を実行します。フォルダ名が違う場合は読み替えてください。追加のパッケージ、登録、鍵は要りません。
    
  
    cd your-world-your-life
    
  
    Node から呼ぶ
    const core = require('./api/core');
const one = core.simulate(417, { locale: 'ja' });
const many = core.batch(417, { count: 3, locale: 'ja' });
const family = core.lineage(2, { era: 'past', year: 1950, country: 'jpn', generations: 2, locale: 'ja' });
    
  
    コマンドで呼ぶ
    node api/cli/index.js simulate --seed 417 --locale ja
node api/cli/index.js batch --seed 417 --count 3 --locale ja
node api/cli/index.js lineage --seed 2 --era past --year 1950 --country jpn --generations 2 --locale ja
    
  
    MCP につなぐ
    MCP 対応アプリに、コマンドを node、引数を展開したフォルダにある api/mcp/index.js の絶対パスとして設定します。標準入出力で動きます。道具は simulate_life、batch_compare、lineage の三つで、読み取り専用です。
    
  
    手元での利用に料金、回数の上限、残り回数の表示、更新日はありません。結果は契約版 1.0.0 の形式で返ります。同じ種・設定・同梱資料なら同じ結果になります。資料や生成器が更新されると、同じ種でも結果が変わることがあります。
    詳しい入出力は展開したフォルダ内の api/README.md と api/core/README.md をご覧ください。
    
  
    データの扱い
    入力した種と生成結果は画面内で扱い、この試用画面から送信・保存しません。ページと資料の読み込みにはサイトへの通信が必要です。手元の道具は外部へ通信しません。MCP を接続したアプリによるデータの扱いは、そのアプリの設定をご確認ください。
