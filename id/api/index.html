Coba alat di perangkatmu

Alat gratis untuk membuat kehidupan melalui Node.js dan MCP. Jalankan semuanya di perangkatmu sendiri.

Unduh dan jalankan

Unduh berkas alat, ekstrak ke folder baru, lalu gunakan Node.js versi 18 atau yang lebih baru. Tidak perlu akun, kunci, paket tambahan, atau biaya. Contoh perintah tersedia di dalam berkas.

Data dan batasan

Alat lokal tidak mengirim masukan maupun hasil ke situs. Mengunduh berkas tetap memerlukan sambungan ke situs. Penggunaan melalui aplikasi yang terhubung ke MCP mengikuti pengaturan privasi aplikasi tersebut. Tidak ada layanan API publik atau batas pemakaian di situs ini.
