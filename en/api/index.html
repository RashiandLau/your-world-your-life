    Run it on your computer
    Download the local tools
    Install Node.js 18 or later. Download the local tools and unpack them into a new folder. The archive contains both api/ and site/assets/. Move into that folder before running the examples below; adjust the folder name if needed. No extra package, account, or key is required.
    
  
    cd your-world-your-life
    
  
    Call from Node
    const core = require('./api/core');
const one = core.simulate(417, { locale: 'en' });
const many = core.batch(417, { count: 3, locale: 'en' });
const family = core.lineage(2, { era: 'past', year: 1950, country: 'jpn', generations: 2, locale: 'en' });
    
  
    Use the command line
    node api/cli/index.js simulate --seed 417 --locale en
node api/cli/index.js batch --seed 417 --count 3 --locale en
node api/cli/index.js lineage --seed 2 --era past --year 1950 --country jpn --generations 2 --locale en
    
  
    Connect with MCP
    In an MCP-capable app, set the command to node and the argument to the absolute path of api/mcp/index.js in the extracted folder. It uses standard input and output. The three read-only tools are simulate_life, batch_compare, and lineage.
    
  
    Local use has no fee, call limit, remaining balance, or reset date. Results follow contract version 1.0.0. The same seed, options, and bundled data reproduce a result. Updating the data or engine may change a result for the same seed.
    See api/README.md and api/core/README.md in the extracted folder for full inputs and outputs.
    
  
    How data is handled
    This trial keeps the seed and result in page memory; it does not submit or save them. Loading the page and its data still contacts the site host. The local tools make no outbound calls. Check the settings of any application you connect through MCP to learn how it handles inputs and results.
